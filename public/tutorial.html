Understanding the Prompt

The prompt shows you where you are in the system:

Switch> User mode (limited access)
Switch# Privileged mode (more access)
Switch(config)# Configuration mode (where changes happen)
Switch(config-if)# Interface configuration mode

⚡ Essential Skills

Tab Completion

Don't type everything! Press TAB to:

  • Complete commands automatically
  • See available options
  • Avoid typos
Example:
Switch> enTAB → Switch> enable

Abbreviations

You can use shortcuts! These all do the same thing:

configure terminal
=
conf t
=
config term

🎨 Network Concepts Visualized

Switch vs Router - What's the Difference?

🔷 Switch

Connects devices in the SAME network

    [Computer A] ───┐
                    │
    [Computer B] ───┤   [SWITCH]
                    │   Layer 2
    [Printer]   ───┤
                    │
    [Computer C] ───┘

    All in Network: 192.168.1.0/24

Think of it as: Connecting computers in your classroom

🔶 Router

Connects DIFFERENT networks together

  [Network A]      [ROUTER]      [Network B]
  192.168.1.0  ───┤ Layer 3 ├─── 10.0.0.0
                  │         │
  [Your Home]     └─────────┘    [Internet]

Think of it as: Connecting your school to the internet

Understanding VLANs

❌ Without VLANs

┌────────────────────────┐
│   ONE BIG NETWORK      │
│                        │
│  👨‍🎓 Students          │
│  👨‍🏫 Teachers          │
│  👔 Admin       [SWITCH]│
│  📹 Cameras            │
│                        │
│  All traffic mixed!    │
└────────────────────────┘
⚠️ Security Risk!

✅ With VLANs

┌────────────────────────┐
│       SWITCH           │
│  ┌──────┐   ┌──────┐  │
│  │VLAN  │   │VLAN  │  │
│  │ 100  │   │ 200  │  │
│  │      │   │      │  │
│  │👨‍🎓👨‍🎓 │   │👨‍🏫👨‍🏫 │  │
│  └──────┘   └──────┘  │
│  Students   Teachers   │
└────────────────────────┘
✅ Secure & Organized!

Real School Network Example:

  • VLAN 10: Student Computers (Limited Internet)
  • VLAN 20: Teacher Computers (Full Access)
  • VLAN 30: Guest WiFi (Internet only)
  • VLAN 40: Security Cameras (Isolated)
  • VLAN 50: Admin/Office (Full network access)

Trunk Ports Explained

Access Port

Carries ONE VLAN only

[Computer] ─── fa0/2 [SWITCH]
  VLAN 100      │
                └─ Only VLAN 100

Like a single-lane road

Trunk Port

Carries MULTIPLE VLANs

           VLAN 100 ──┐
[SWITCH A]            ├─ g0/1 (TRUNK)
           VLAN 200 ──┘
                    ║
              ══════╬═══════
                    ║
           VLAN 100 ──┐
[SWITCH B]            ├─ g0/1 (TRUNK)
           VLAN 200 ──┘

Like a multi-lane highway

SSH Security

🚫 Telnet (INSECURE)

You ───> "password: secret123" ───> Router

⚠️  Text is UNENCRYPTED!
🕵️ Hacker can read it:
   "I see: password: secret123"
   ✓ I'm in!

✅ SSH (SECURE)

You ───> 🔒 %#^&*@!$^&* ───> Router

✅ Data is ENCRYPTED!
🕵️ Hacker sees gibberish:
   "%#^&*@!$^&*"
   ✗ Can't read it!

🎮 Command Cheat Sheet

Navigation Commands

enable Enter privileged mode (> becomes #) Try It
configure terminal Enter configuration mode Try It
exit Go back one level Try It
end Jump back to privileged mode Try It

Basic Configuration

hostname MySwitch Set device name Ex. 1
enable secret MyPass Set admin password Ex. 1
write memory SAVE configuration (important!) All

Interface Commands

interface g0/1 Enter interface configuration Ex. 2,5
ip address 10.0.0.1 255.255.255.0 Set IP address Ex. 2,5
no shutdown Turn interface ON Ex. 2,5

VLAN Commands

vlan 100 Create VLAN 100 Ex. 3
name Sales Name the VLAN Ex. 3
switchport mode access Make it an access port Ex. 3
switchport access vlan 100 Assign port to VLAN 100 Ex. 3
switchport mode trunk Make trunk port Ex. 4

Show Commands (Information)

show running-config See all configuration Try It
show ip interface brief See all interfaces Try It
show vlan brief See all VLANs Try It
show ip route See routing table Try It

💡 Tips for Success

1. Read Carefully

Read the entire exercise before starting. Pay attention to exact numbers, IPs, and names.

2. Use TAB

Seriously, use TAB constantly. It prevents typos and shows you what's available.

3. Save Last

Configure everything correctly, THEN save with write memory

4. Check Your Work

Use show commands to verify your configuration before saving.

5. Don't Rush

Accuracy matters more than speed. Take your time!

6. Use Hints

Don't feel bad about using hints - that's how we all learn!

🚨 Common Mistakes to Avoid

❌

Forgetting "no shutdown"

Interface configured but won't work!

✅ Always add no shutdown to interfaces

❌

Saving too early

Partial config is saved, exercise won't pass!

✅ Save with write memory ONLY when done

❌

Wrong IP or VLAN number

192.168.1.10 instead of 192.168.1.100

✅ Double-check every number
